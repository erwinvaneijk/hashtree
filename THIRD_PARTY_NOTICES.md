# Third-party notices

This project depends on third-party Rust crates, each under its own license terms.

To generate a current dependency license report, use one of these tools:

```bash
cargo install cargo-license
cargo license --authors --do-not-bundle
```

or

```bash
cargo install cargo-about
cargo about generate about.hbs > THIRD_PARTY_LICENSES.txt
```

For official release artifacts, regenerate this report from the exact commit/tag being released.
